# Rock, Paper, Scissors

## Data statement — planned collection

We plan to collect photographs of our group members' hands making rock, paper and scissors gestures. Approved images will be stored in this public GitHub repository. We will obtain each participant's agreement to collection and publication before including their photos, and crop out faces or discard those images.

Each member still needs to record whether they are comfortable with public sharing and why. Anyone outside the group will be asked in advance.

## About

A Holberton machine learning project using [Teachable Machine](https://teachablemachine.withgoogle.com/) to recognise hand gestures and investigate what the model actually learns.

## Initial plan

Collect at least **50 images per gesture**, using all three members' hands and varied angles, lighting and backgrounds. Train and export the model, then exchange evaluations with another group using **30 unseen images: 10 per gesture**.

**Status:** initial repository setup. The dataset, model, screenshots and evaluation findings will be added as the project progresses.
