# Source for external rock images

The files `external_rock_001.png` through `external_rock_050.png` were selected from:

- SmallRPSDataset by Todd Kerpelman: https://github.com/ToddKerpelman/SmallRPSDataset
- Original Rock-Paper-Scissors image dataset by Julien de la Bruere-Terreault (DrGFreeman): https://github.com/DrGFreeman/rps-cv-data-science

The images are used as external training data for this machine learning project. The image contents were not modified; the files were only renamed.
